One short pickup line an AI agent could actually say out loud to a person.
No setup, no explanation after it — the line lands on its own.

The program (`main.ts`, Node 22) writes the line to `/output/entry.txt`:
one UTF-8 text, 1–200 characters, no trailing newline.

Entry for [The Perfect Pickup Line](https://make.fun/c/u-pucuys-the-perfect-pickup-line-f6725cf6)
on make.fun. See `PREDICTION.md` for the honest pre-build estimate
(GAMBLE — blind board, top 5 invisible) and `candidates.md` for the
five fresh candidates and the head-to-head tournament that picked the winner.
